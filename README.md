# Cente - Python 项目常驻托盘与后台管理器

> ⚡ **轻量、低依赖、专为 Python 开发者打造的后台项目托盘托管中心**

---

## 🌟 核心特性

- **常驻系统托盘（右下角）**：开启开机自启后，登录系统时自动驻留托盘，不占用任务栏空间；手动启动打开控制面板。
- **无黑框后台静默运行**：通过 Windows 底层 `CREATE_NO_WINDOW` 机制彻底屏蔽黑框控制台，再也不用开一堆命令行窗口。
- **动态右键托盘菜单**：
  - 点击左键：快速呼出/隐藏主控制面板。
  - 右键菜单：实时列出各个 Python 项目（例如 `● notion` 运行中 / `○ web-api` 已停止）。
  - 支持直接在右键菜单中一键 **重启**、**停止**、**启动**、**查看日志**、**打开目录**。
  - 支持 **全部一键启动**、**全部一键停止**、**安全退出**。
- **智能环境与入口识别**：
  - 添加项目目录时，自动探测并优先使用项目内的虚拟环境（`.venv`、`venv` 中的 `python.exe`），无需全局 Python 污染。
  - 自动识别 `run.py`、`main.py`、`app.py`、`server.py` 等常见启动入口。
- **实时日志与持久化**：
  - 项目标准输出/错误输出（`stdout`/`stderr`）自动重定向并写入 `cente_logs/<项目ID>.log`。
  - 界面提供实时滚屏日志查看面板，也可一键通过系统记事本打开。
- **进程树级彻底强杀**：
  - 采用 Windows 进程树强杀机制（`taskkill /F /T`），彻底解决 FastAPI / Uvicorn / Flask 重新加载或多进程子进程残留占端口的问题。
- **极致轻量（~10MB）**：
  - 基于 Rust + Tauri 2 构建，直接复用系统自带的 Edge WebView2 内核，无需 Electron 几百兆的浏览器依赖，内存占用极低。

## 🚀 快速启动

### 下载正式版（无需编译）
从 [GitHub Releases](https://github.com/btwo163/cente/releases/latest) 下载 `cente-windows-x86_64.exe`，放入独立目录，重命名为 `cente.exe` 后双击运行。适用于 Windows x64，需要系统已安装 Edge WebView2。程序配置和日志保存在程序目录。

默认更新源为 `btwo163/cente`，启动时自动检查新版；也可打开全局设置，点击“检查更新”及“下载并重启更新”。安装更新会停止托管项目，更新完成后需手动启动项目。

以下启动方式用于已克隆源码的开发环境。

### 方式一：双击启动（推荐）
在 `cente` 目录下双击运行：
```cmd
start.bat
```

### 方式二：手动运行
直接运行编译好的轻量可执行文件：
```cmd
src-tauri\target\release\cente.exe
```

### 方式三：开发模式热重载
```cmd
cd src-tauri
cargo run
```

## 📁 目录结构

```
cente/
├── start.bat               # Windows 一键启动脚本
├── ui/                     # 前端界面（纯原生 HTML/CSS/JS，极简无打包构建负担）
│   ├── index.html          # 主界面结构
│   ├── style.css           # 深色现代卡片流样式
│   └── app.js              # 前端交互与 Tauri IPC 调用
├── src-tauri/              # Rust 后台核心
│   ├── src/
│   │   ├── main.rs         # 启动入口
│   │   ├── lib.rs          # Tauri 插件装配与窗口关闭拦截（防误触退出）
│   │   ├── tray.rs         # 系统右键动态托盘菜单逻辑
│   │   ├── process_mgr.rs  # 进程生命周期、无黑框托管、日志异步采集
│   │   ├── commands.rs     # 供前端调用的安全 IPC 命令
│   │   └── models.rs       # 数据定义
│   └── Cargo.toml          # Rust 依赖配置与体积优化
├── cente_projects.json     # 项目配置持久化存储
└── cente_logs/             # 托管项目的历史日志输出目录
```

## 💡 使用小贴士

**程序更新**：全局设置中新增 GitHub 发布仓库、启动时自动检查、手动检查及“下载并重启更新”。使用前需要公开仓库及匹配的正式 Release 附件。发布规范、校验和恢复方式见 [UPDATING.md](UPDATING.md)。

项目配置中的“显示在托盘菜单”默认开启（包括已有项目）。取消勾选并保存后，该项目及其操作项立即从托盘右键菜单隐藏；主界面仍可正常管理。重新勾选并保存即可恢复显示。此选项只影响菜单展示，不改变项目运行状态或“全部启动／全部停止”的作用范围。

在项目配置中填写“访问地址”（例如 `http://localhost:8000`）并保存后，可通过项目“…”菜单中的“立即访问”用默认浏览器打开。托盘右键菜单中直接点击运行中的项目名称也会打开该地址；未配置地址时会提示填写。超过 3 个项目时，运行中项目名称仍可直接点击，其管理操作收纳在紧邻的“项目操作”子菜单中。

1. **全局设置**：点击顶部搜索框右侧的设置图标，可开启或关闭“开机自动启动”。设置立即保存到当前 Windows 用户的启动项；登录系统后 Cente 自动驻留托盘，手动启动仍打开主窗口。此设置只启动 Cente，不自动启动托管项目。若移动了 `cente.exe`，请在新位置重新开启此开关；若在 Windows“启动应用”中禁用了 Cente，请在那里重新启用。
2. **统一滚动条**：运行日志、项目列表和配置面板使用深色细圆角滚动条，支持悬停与拖动反馈。
3. **防误触设计**：点击主面板右上角的 **关闭 (X)** 时，窗口只会静默隐藏到系统托盘，后台各项目仍持续稳定运行。
4. **彻底退出**：如需完全关闭所有项目并退出 Cente，请在系统托盘图标上右键，选择 **“❌ 退出 Cente”**。
